# Credits

No third-party files were used. Everything new was generated for this mod with fal (um fal):

| Asset | How | Tool |
|---|---|---|
| Demon horns, Butcher's cleaver, loot chest (concept images) | text to image | fal-ai/nano-banana-2 |
| sigf_horns, sigf_cleaver, sigf_chest (3D models) | image to 3D, converted to GTA V props with the kit's model.ps1 | fal-ai/trellis-2 |
| Health and mana orb art | text to image, mana orb is a hue-shifted copy | fal-ai/nano-banana-2 |
| gold, levelup, portal sounds | text to sound effect | fal sfx |
| The Butcher's voice line | text to speech, pitched down with ffmpeg | fal ElevenLabs v3 |

All other content (peds, props, particles, explosions, weapons, the Sandy Shores airfield) is GTA V's own, used through FiveM.
The mod code is original; "Diablo" is only the theme and nothing from that series was copied.
