# Diablo Takeover

**gta5** × Diablo · visual · idea by the team

Bring Diablo into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned the Sandy Shores airfield into Diablo: horned demons, loot beams, a holy nova on level-up, and a fat Butcher who dies to one rocket.

## Install

Put the folder in your FiveM server's resources folder as sigf_mod, add "ensure sigf_mod" to server.cfg, then start the server and join. Demons, loot and the orbs appear by themselves.
